# Skill Management

List, search, create, edit, validate, install, or remove Codex skills in the requested scope. Use lowercase hyphenated names, valid two-field frontmatter, concise native instructions, and deterministic resources. Confirm before overwrite or destructive removal, and invoke skills with `$name`.
