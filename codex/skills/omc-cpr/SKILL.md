# Commit, Push, Request

Inspect status, diff, repository guidance, and target branch. Present the intended commit and remote effects before any push or pull-request creation, because those actions change external state. After authorization, use one bounded git specialist or execute directly, follow the repository commit protocol, verify the remote result, and never include unrelated changes.
