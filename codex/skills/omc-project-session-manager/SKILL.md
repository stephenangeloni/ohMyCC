# Project Session Manager

Inspect existing branches, worktrees, session metadata, and repository naming rules. Create or resume the smallest isolated worktree and optional terminal session requested, preserve dirty worktrees, and record the issue or feature context. Ask before remote branch creation, deletion, or other destructive Git operations.
