# Skillify

Extract the reusable trigger, procedure, resources, safety boundaries, and verification from the session. Remove project-specific accidents and all secrets, write concise Codex-native instructions, generate UI metadata when useful, and validate the skill. Do not install or overwrite it without the requested scope and authorization.
