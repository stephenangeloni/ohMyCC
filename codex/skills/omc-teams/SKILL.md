# OMC Teams

Prefer Codex native subagents for ordinary in-session parallel work. When the user explicitly requests the process-based OMC team runtime, verify the `omc` CLI and tmux environment, define bounded worker tasks, launch the supported Codex workers, monitor terminal states, and clean up only the created team resources.
