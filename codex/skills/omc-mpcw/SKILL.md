# Merge Project Worktree

Inspect the source worktree, target branch, uncommitted changes, active processes, and upstream state. Present the merge, push, worktree removal, and branch-deletion actions before execution. After explicit authorization, merge and verify first, then remove only the identified clean worktree and branches.
