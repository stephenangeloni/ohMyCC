# CCG

Use the existing `omc ask` CLI to request bounded independent answers from the available Claude, Codex, and Gemini providers. Preserve each raw response, compare agreements and contradictions, verify important claims locally, and return one synthesis with evidence boundaries. Continue with the providers that are available and name any missing lane.
