# Deep Init

Map repository boundaries, existing guidance, build systems, and nested ownership. Keep cross-cutting rules at the root and place directory-specific rules in nested `AGENTS.md` files. Preserve user guidance, remove duplicated or self-evident text, and validate that each file applies only to its subtree.
