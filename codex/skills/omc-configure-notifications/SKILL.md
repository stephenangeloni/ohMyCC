# Configure Notifications

Inspect the existing notification configuration and supported Codex hook events. Add or update only the requested Telegram, Discord, or Slack destination through the repository's existing notification utilities, keep credentials out of output and version control, and preserve unrelated hooks. Test with a non-sensitive dry run when the integration supports it.
