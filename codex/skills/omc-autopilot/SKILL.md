# Autopilot

Clarify only material ambiguity, create a test-first plan, then execute through implementation, review, and adversarial QA. Use bounded native subagents for independent exploration, implementation, review, and verification. Keep one leader responsible for integration, continue while safe work remains, and stop only with fresh evidence or a genuine blocker.
