# HUD

Detect whether the active Codex environment exposes an OMX HUD or compatible status display. Use its supported configuration command when present, preserve unrelated settings, and show the resulting configuration. If no native display surface exists, explain the exact capability gap instead of editing Claude status-line configuration.
