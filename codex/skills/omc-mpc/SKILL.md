# Merge Project Change

Inspect branch state, worktree cleanliness, upstreams, tests, and the repository's merge policy. Present the exact merge, push, and branch-deletion actions before executing them. After explicit authorization, perform the smallest non-interactive Git sequence, verify the remote state, and never discard uncommitted work.
